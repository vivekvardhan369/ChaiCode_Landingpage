# Auquan, AI Agents for Deep Work in Finance

## Overview

Auquan leverages AI to deliver deep insights in finance, allowing professionals to focus on outperformance while the AI handles the grunt work. This project is bootstrapped with [Vite](https://vitejs.dev/).

## Features

- AI-driven insights for asset management
- Pre-written reports for analysts
- Credit pre-diligence support
- Thematic and local insights for emerging markets
- Tracking underreported small cap company developments and risks

## Project Setup

### Prerequisites

Ensure you have the following installed on your machine:

- [Node.js](https://nodejs.org/) (version 14.x or later)
- [npm](https://www.npmjs.com/) (version 6.x or later)

### Installation

1. Clone the repository:

```sh
git clone https://github.com/your-username/auquan-ai-agents.git
cd auquan-ai-agents

```
2. Install the dependencies:

```sh
npm install
```

### Development
To start the development server with hot-reloads:

```sh
npm run dev
```

### Production
To compile and minify the project for production:

```sh
npm run build
```

### Customize Configuration

See [Vite Configuration Reference.](https://vitejs.dev/config/)

### Usage

1. Start the development server:

```sh
npm run dev
```
2. Open your browser and navigate to http://localhost:3000 to see the application in action.
